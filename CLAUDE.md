# Conduit

Conduit is a job and workflow platform for March. It provides primitives for defining, scheduling, and executing jobs and multi-step workflows.

## Project Structure

- `lib/` — library source code
- `test/` — tests
- `specs/` — design specifications

## Development

This is a March library project. Use `forge test` to run the test suite.

## Dependencies

- `depot` — March's standard data/storage library (sibling directory)
